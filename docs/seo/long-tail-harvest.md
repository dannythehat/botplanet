# Long-tail harvest — every category, 6 August 2026

**567 keywords with measurable US volume**, from `related_keywords` across nine categories.
Cost: about $2.13 total. Every figure is DataForSEO, US, August 2026.

## Why this did not exist before

`/dataforseo_labs/google/related_keywords/live` accepts EXACTLY ONE TASK PER REQUEST.
The script sent every lead in one batched request, the API rejected it every time with
`40000 You can set only one task at a time`, and the fallback retried only the first four
leads. So every run ever done harvested at most four leads of long-tails and discarded the
rest — and the earlier note that the endpoint "returns almost nothing" was measuring the
bug, not the endpoint. One task per request now. A fourteen-lead category costs about a
penny and a half for its whole long-tail set.

Terms already assigned as a primary or secondary keyword are marked ALREADY OWNED.
